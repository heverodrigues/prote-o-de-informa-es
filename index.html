🔒 O que é criptografia?

Criptografia é uma técnica utilizada para transformar informações em códigos, dificultando o acesso de pessoas não autorizadas.

Exemplo:

Senha original: 123456

Senha transformada: 234567

Nesse exemplo, cada número foi aumentado em uma unidade. É uma demonstração simples de transformação, não uma criptografia segura.

🛡️ O que é Hash?

Hash é uma função que transforma uma informação em uma sequência de caracteres de tamanho definido. Ele é utilizado para verificar a integridade de dados e armazenar senhas de maneira mais segura.

Um exemplo conhecido é o SHA-256, que gera um resultado hexadecimal de 64 caracteres.

💻 Criptografia com Python

senha = "123456"
senha_criptografada = ""

for numero in senha:
    numero = int(numero) + 1
    senha_criptografada += str(numero)

print(senha_criptografada)

Exemplo de Hash com Python

import hashlib

senha = "123456"

hash_senha = hashlib.sha256(
    senha.encode()
).hexdigest()

print(hash_senha)
